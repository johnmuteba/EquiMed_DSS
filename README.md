# EquiMed_DSS

EquiMed_DSS is a comprehensive Python library for assessing reliability, equity, governance, and intersectionality in clinical AI systems using 19 novel metrics.

- **Domain 2: Fairness, Equity, and Ethics Assessment**
    - Hierarchical Equity Ratio (HER)
    - Harm-Adjusted Fairness Gap (HAFG)
    - Ethical Risk Index (ERI)
    - Intersectional Bias Score (IBS)

- **Domain 3: Governance and Transparency Assessment**
    - Temporal Fairness Drift (TFD)
    - Audit Traceability Score (ATS)
    - Governance Compliance Index (GCI)

- **Appendix Metrics**
    - Advanced Reliability (BCI, SPA, Bias Concentration)
    - Advanced Information-Theoretic (MIC, JSD, WD)
    - Advanced Network and Governance (NM, TS, RCS)

See the `examples/` directory for usage examples of each domain.
